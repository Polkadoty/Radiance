# Reimagined reference gallery

The target is Complementary **Reimagined**: Minecraft-scale square clouds and restrained water detail. The official site describes Reimagined as preserving Minecraft's visual elements, while Unbound has a more realistic default style. [Official style explanation](https://www.complementary.dev/shaders/#style-section).

[Open the official Reimagined gallery](https://modrinth.com/shader/complementary-reimagined/gallery). The images below are remote links to that project's own gallery; no image assets are bundled or reused in the shaderpack.

Source membership and original image URLs were checked against the [official project's Modrinth metadata](https://api.modrinth.com/v2/project/complementary-reimagined) on 2026-09-05. Images belong to their respective creators. These links identify the desired aesthetic; this prototype does not claim visual parity.

The user's v0.2-versus-Advanced screenshots are the authoritative local comparison. They show oversized slabs and rectangular water-reflection patches in v0.2, with the desired smaller cloud scale and continuous water in Advanced. Vanilla measurements were independently verified in the local Minecraft 1.21.1 sources and Radiance CloudRenderer: 12-block XZ cells, 4-block thickness, Overworld cloud altitude 192. v0.3 uses those footprints and altitude, with restrained 4/5/6-block cloud tops.
